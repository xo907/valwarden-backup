# valwarden-backup
Rather than backing up the Vaultwarden database. this script will allow you to backup your Vaultwarden (and/or Bitwarden) account(s). 

How to install and use:
1. Create a folder anywhere on your PC and place the run.bat file into it.
2. Launch the run.bat file in the folder and it will create the necessary directories and download the bw.exe file.
3. When all is completed, use option 1 to add your account. Follow the prompts.
4. When your account(s) is/are added, you can either give it a test run (option 2) or just immediately setup a task scheduler (option 3).

It's as simple as that.
